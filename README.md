# To-Do List

A simple to-do list app: add, edit, delete, and complete tasks, filter by status, and your tasks are saved in the browser.

Live demo: https://alexspearsi.github.io/to-do-list/

## Stack

React, TypeScript, Vite, CSS Modules, localStorage.

## Commands

- `npm install` — install dependencies
- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint
- `npm run format` — run Prettier
